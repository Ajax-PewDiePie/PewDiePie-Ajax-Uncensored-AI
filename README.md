## Getting Started
1. Download the 9B pack.
2. Install Ollama. Pull Ajax.
3. Point Odysseus at `http://localhost:11434/v1`.
4. Notes in `files/notes/`.

```
ollama pull ajax:9b
ollama run ajax:9b
```

**qwen 3.5 9b vs ajax?**
Ajax is the Odysseus fine-tune. The base Qwen 3.5 9B tag is `qwen3.5:9b`.
